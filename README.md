# 📊 Briefing Forex — Abertura dos EUA

Briefing diário de Forex do **Marcio Militão**, publicado de **segunda a sexta às 9h35 de Nova York** (11h35 ou 10h35 em Brasília, conforme o horário de verão dos EUA) — logo após a abertura do mercado americano.

## O que tem em cada briefing

- Preço, variação do dia, máxima/mínima e leitura curta de cada ativo
- O bloco **"O que está mexendo com o mercado hoje"** (Fed, inflação, payroll, yields...)
- **Gráfico do dia**: variação % de cada ativo, da maior alta para a maior queda, com o selo de viés **COMPRA / VENDA / ESPERAR**
- **Dicas do dia** com suporte e resistência de cada ativo
- Linha de atenção: o ativo mais volátil do dia

## Aviso

Este briefing é **informação para acompanhar o mercado** — não é recomendação de compra ou venda, nem promessa de lucro. Os selos COMPRA/VENDA/ESPERAR são o viés (leitura) do dia, para ajudar na decisão de quem lê.
